# Mei Mobile A+B Classic iOS Design Board

Open `index.html` in a browser to review the static proposal.

Direction:
- Classic iOS palette: crisp white, grouped light gray, graphite text, system-blue actions.
- Classy wardrobe feel: Today and Closet are photo-first, with navy, camel, sage, and charcoal garments.
- Closet view sizing: Compact, Medium, and Large wardrobe photo sizes via a dropdown.
- Target touch sizes: 44-54px for buttons, chips, rows, and icon controls.
- Primary screens covered: Today, Closet, Stella, You.

This is design-only. It does not depend on Expo, Supabase, or local services.
